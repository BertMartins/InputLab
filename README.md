# InputLab

Diagnóstico visual de teclado, mouse, scroll e drift direto no navegador.

🔗 **Demo:** https://bertmartins.github.io/InputLab/

## 🛠️ Tecnologias

- HTML
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/InputLab.git
cd InputLab
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
